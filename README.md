# Голосовые траты

Диктофон для расходов в тенге. Нажимаете микрофон, говорите «вчера потратил
тысячу двести на такси» — приложение само вытаскивает сумму, валюту, категорию и
дату, и кладёт запись в список. Всё работает в браузере: речь распознаёт сам
браузер, данные лежат в localStorage устройства, сервера нет.

Валюта по умолчанию — тенге. Понимается и русская, и казахская речь: язык
распознавания переключается в настройках, там же можно сменить валюту на рубли,
доллары, евро и другие.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:5173` в Chrome и разрешите доступ к микрофону.

Проверка разбора фраз:

```bash
npm run test
```

Сборка для публикации:

```bash
npm run build
```

Готовые файлы кладутся в `dist/` — это обычная статика, её можно выложить на
GitHub Pages, Netlify, Vercel или любой хостинг. Микрофон работает только на
`https://` или на `localhost`, так что для телефона нужен именно https-адрес.
После открытия сайта на телефоне выберите в меню браузера «Добавить на главный
экран» — приложение поставится как обычная иконка и будет открываться офлайн.

## Публикация на GitHub Pages

Создайте пустой репозиторий на github.com, затем свяжите с ним папку проекта:

```bash
git remote add origin https://github.com/ВАШ-ЛОГИН/ИМЯ-РЕПОЗИТОРИЯ.git
git push -u origin main
```

В настройках репозитория откройте Settings → Pages и в поле Source выберите
GitHub Actions. После этого каждый push в ветку `main` сам собирает проект и
выкладывает его: workflow лежит в
[.github/workflows/deploy.yml](.github/workflows/deploy.yml) и перед сборкой
прогоняет проверки разбора фраз.

Адрес сайта будет `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`. Сборка собрана
с относительными путями (`base: './'` в [vite.config.js](vite.config.js)), поэтому
работает в подпапке с любым именем репозитория и переименование ничего не сломает.

## Что понимает

| Фраза | Результат |
| --- | --- |
| потратил 1500 тенге на кофе | 1500 ₸, кафе и рестораны |
| тысяча двести на продукты | 1200 ₸, продукты |
| такси 2500 тг | 2500 ₸, транспорт |
| двадцать пять тысяч триста за ноутбук | 25 300 ₸, техника |
| полторы тысячи в аптеке | 1500 ₸, здоровье |
| 20 долларов на подписку | 20 $, связь и подписки |
| вчера 300 на обед | 300 ₸, вчерашняя дата |
| кофе двести и такси четыреста | две отдельные записи |
| получил зарплату 500 тысяч | +500 000 ₸, доход |

По-казахски, если в настройках выбран язык Қазақша:

| Фраза | Результат |
| --- | --- |
| екі мың теңге такси | 2000 ₸, транспорт |
| жүз мың теңге пәтер | 100 000 ₸, жильё |
| екі жүз елу теңге нан | 250 ₸, продукты |
| он бес мың теңге дәріхана | 15 000 ₸, здоровье |
| кеше алты мың теңге жұмсадым | 6000 ₸, вчерашняя дата |

Числа понимаются и словами, и цифрами: «пятьсот», «1500», «500к», «3 тыс»,
«полторы тысячи», «екі жүз елу», «жүз мың». Валюта слышится как «тенге», «теңге»,
«тг», а также «рублей», «долларов», «евро». Даты — «сегодня», «вчера»,
«позавчера», «три дня назад», «кеше». Доход отличается от расхода по словам
«получил», «зарплата», «вернули», «кэшбэк», «жалақы».

Казахские числительные включаются только вместе с языком Қазақша. Иначе слово
«он» (десять по-казахски) превращало бы русское «он потратил тысячу» в десятку.

Разделитель тысяч не путается с дробью: «2,500», «2. 500» и «1.000.000» читаются
как 2500 и 1 000 000, а «1,5 доллара» и «10,50» остаются дробными. Распознавание
речи часто вставляет такой разделитель само.

Под микрофоном показывается расслышанная фраза, поэтому сразу видно, если
распознавание услышало не то слово. Исходная фраза хранится в записи и видна в
форме правки.

Если сумму разобрать не удалось, запись всё равно создаётся и сразу открывается
форма, чтобы вписать сумму руками. Любую запись можно поправить тапом по ней.

## Как устроено

| Файл | Зачем |
| --- | --- |
| [src/lib/numbers.js](src/lib/numbers.js) | числительные словами: «две тысячи пятьсот» → 2500 |
| [src/lib/parse.js](src/lib/parse.js) | разбор фразы: сумма, валюта, дата, доход или расход |
| [src/lib/categories.js](src/lib/categories.js) | категории и ключевые слова к ним |
| [src/lib/storage.js](src/lib/storage.js) | хранение в localStorage и выгрузка CSV |
| [src/hooks/useSpeech.js](src/hooks/useSpeech.js) | распознавание речи через Web Speech API |
| [scripts/test-parser.mjs](scripts/test-parser.mjs) | проверки разбора фраз |

Категории подбираются по ключевым словам, список легко расширить: добавьте слово
в нужную категорию в `src/lib/categories.js`. Там уже есть местные названия:
Магнум, Small, Галмарт, inDrive, Bolt, Wolt, Kcell, Altel, дүкен, дәріхана.

## Ограничения

Web Speech API есть в Chrome, Edge и Safari, но не во всех браузерах. В Firefox
распознавание не работает — там остаётся поле ввода текстом, оно проходит через
тот же разбор. Распознаванию нужен интернет, потому что браузер отправляет звук
на сервер распознавания Google или Apple. Записи хранятся только на этом
устройстве и в этом браузере, синхронизации между устройствами нет — для
переноса есть выгрузка в CSV.
